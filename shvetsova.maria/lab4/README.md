# Лабораторная работа 4

## Задание

Вариант 28. Создать класс Movie для хранения названия фильма, режиссера и
массива имен актеров. Реализовать методы добавления актера в массив, удаления
актера по имени и получения количества актеров. Реализовать функции, которые
группируют фильмы по режиссёру, возвращающие уникальных актёров, группирующих
фильмы по количеству актёров, возвращающих фильмы, в которых снялся конкретный
актёр и возвращающих список всех названий фильмов. Реализовать пользовательский
интерфейс со списком карточек фильмов, кнопками “Добавить фильм”, “Удалить
фильм”, формой создания фильма, кнопками “Добавить актера”, “Удалить актера” и
формой добавления нового актера.

## Реализация

В model.js реализован класс Movie и функции работы с коллекцией:
groupMoviesByDirector, getUniqueActors, groupMoviesByNumOfActors,
getMoviesByActor и findAllMovieNames. Файлы index.html, styles.css и main.js
создают карточки фильмов, форму добавления фильма и кнопки управления фильмами и
актерами. После каждого изменения DOM и localStorage обновляются автоматически.
Все операции добавления и удаления выполняются через Promise и setTimeout.

## Запуск

Откройте `index.html` в браузере.
