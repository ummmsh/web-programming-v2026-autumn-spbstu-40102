# Лабораторная работа 3

## Задание

Вариант 28. Реализуйте функцию findMostFrequent(arr), которая возвращает самый
часто встречающийся элемент в массиве.

## Реализация

Функция `findMostFrequent` находит наиболее часто встречающийся элемент в
массиве за один проход. Используется объект `frequency` как хеш-таблица для
подсчета количества вхождений каждого элемента. По мере заполнения таблицы
отслеживается текущий максимум. Функция возвращает элемент с наибольшим
счетчиком, а в случае пустого массива - `undefined`.

## Запуск

Импортируйте именованный export `findMostFrequent` из `solution.js` как ES
module.
