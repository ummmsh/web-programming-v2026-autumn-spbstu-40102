# Лабораторная работа 5

## Задание

Вариант 28. Создать компонент списка в виде дерева (tree). Добавить возможность
скрывать/раскрывать ветки.

## Реализация

Приложение создано на React и запускается с помощью Vite. Компонент TreeNode -
переиспользуемый узел дерева с состоянием expanded, который раскрывается и
скрывается по клику. Компонент BookTree строит из данных четырёхуровневое
дерево: автор -> издательство -> жанр -> название книги, рекурсивно вкладывая
TreeNode друг в друга. Данные каталога хранятся в assets/books.js.

## Запуск

Выполните `npm install`, затем `npm run dev` в каталоге лабораторной.
