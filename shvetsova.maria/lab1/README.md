# Лабораторная работа 1

## Задание

Вариант 28.

## Реализация

В файле `index.html` создана базовая структура страницы с заголовком, футером и основным блоком, который делится на боковую панель и область контента.
В файле `style.css` с помощью Flexbox реализована верстка макета: контейнер растянут на всю высоту экрана, боковая панель зафиксирована на ширине 300px, основной контент занимает все оставшееся пространство и всем блокам задана рамка толщиной 1 px.

## Запуск

Откройте `index.html` в браузере.
