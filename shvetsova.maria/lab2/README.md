# Лабораторная работа 2

## Задание

Вариант 28. Написать функцию calculateExpression(expr), вычисляющую значение
математического выражения в строке (например, "2 + 3 * 4" → 14)

## Реализация

Функция `calculateExpression` вычисляет значение математического выражения,
переданного в виде строки, с учетом приоритета арифметических операций. Сначала
выражение разбивается на токены (числа и операторы) с помощью регулярного
выражения. Затем выполняются два прохода: на первом применяются умножение и
деление, на втором - сложение и вычитание.

## Запуск

Импортируйте именованный export `calculateExpression` из `solution.js` как ES
module.
